performance and final candidate gates are still tracked separately.

## Changes

- Publishable `levit_lints` 0.1.0, native root-level plugin configuration,
  `await_levit_lifecycle`, `avoid_global_levit_in_widgets` and
  `discarded_levit_future`. Resolved library/hierarchy identity, inherited
  application overrides and aliased imports are covered. No general cancellation
  or control-flow proof is claimed. Corrected old duplicate fixture declarations.
- Runnable task-board save/upload groups, cancellation, sibling failure and
  repository drain; session replacement/loading/retry/coalescing and typed store
  override widget tests with actual ancestor inheritance. The catalog supplies
  searchable pagination and optimistic rollback.
- Scopes → owners → state → widgets onboarding, advanced helpers, current
  architecture/proposal dispositions and a reconciled cumulative migration guide.
- Coordinated 0.1.0 package versions, Dart 3.12+/Flutter 3.44+ minimums. Persistence
  remains independently planned; inspector UI stays private. All 22 packages
  resolve together. Tooling packages are included in CI/coverage/Pana discovery
  where applicable; native consumer and browser checks have repeatable scripts.
- Workspace formatting and mechanical SDK analyzer corrections. Explicit Flutter
  text-controller disposers corrected in the original task-board example.
