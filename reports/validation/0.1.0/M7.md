## Scope and implementation

- `reports/release_0.1.0_plan.md` records the amended release objective, milestones
  and acceptance gates. `reports/ecosystem_roadmap.md` carries the complete persistence
  scope, including its interfaces/codecs, memory/IO/SharedPreferences adapters,
  migrations/diagnostics, persistent task-cache adapter and restoration examples.
  The ecosystem has independent versions, compatibility tests and release gates.
- `LxValueListenable<T>` accepts any `LxReadable<T>`, borrows its current value,
  subscribes only while it has listeners, and implements LevitDisposable. Disposal
  is idempotent and releases only the subscription, including during notification.
  The Flutter kit re-exports `asValueListenable()` without a new dependency.
- `LxCountdown` uses a monotonic Stopwatch with an optional controlled stopwatch for
  deterministic tests. It catches up after delayed callbacks, handles partial final
  intervals, freezes sub-tick time on pause, and defines start/stop/resume explicitly.
  Disposal cancels timing immediately and awaits reactive cleanup. The time mixin
  drains earlier work, cancels all countdowns before awaiting cleanup, and preserves
  both earlier lifecycle and countdown errors.
- The scoped Flutter example uses the recommended kit import and explicit bootstrap;
  ValueListenableBuilder observes the borrowed countdown state. Run from
  `packages/kits/levit_flutter/example` with
  `flutter run -d chrome -t lib/countdown_interop.dart`.
